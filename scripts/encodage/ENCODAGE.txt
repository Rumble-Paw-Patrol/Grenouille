Remplacer <depot> par le dossier du dépôt et <encodeur> par le nom de l'encodeur (ex. birdnet_v3).

pour lancer l'encodage dans powershell :

Start-Process powershell -WindowStyle Hidden -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','<depot>\scripts\encodage\encode_modele.ps1','-Encoder','<encodeur>'

voir où ça en est :

Get-Content <depot>\rapports\embed_<encodeur>.log -Tail 3

arrêter l'encodage :

Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*encode_modele.ps1*' -or $_.CommandLine -like '*encode_pistes.ps1*' -or $_.Name -eq 'blanci.exe' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }


Encodage du corpus entériné (contrôle qualité clos le 20/11/2026)
-----------------------------------------------------------------

Le corpus : annotations\corpus_20261120\ (corpus.csv : chaque enregistrement retenu et sa piste ; LISEZMOI.md : comptes et empreinte de la base).
À partir d'ici, ne plus lancer blanci flag, blanci qc ni blanci ingest : ils recalculeraient les drapeaux, donc le corpus.

Les deux disques branchés (BLANCI_2023-24 et BLANCI_2025-26, F:), le poste d'annotation fermé, dans PowerShell. Les commandes se tapent l'une après l'autre ; chacune attend la fin de la précédente.

0. aller dans le dépôt :

Set-Location C:\Users\ll34272\Grenouille

1. sauvegarder la base telle qu'entérinée (copie datée sur F:) :

uv run python -c "import sqlite3; s=sqlite3.connect(r'C:\Users\ll34272\base_blanci\blanci.sqlite'); d=sqlite3.connect(r'F:\data\db\blanci_corpus_20261120.sqlite'); s.backup(d); d.close(); print('ok')"

2. les listes et les chiffres (lecture seule) :

uv run python scripts/encodage/file_pistes.py

   -> rapports\encodage_pistes\LISEZMOI.md, <modèle>.csv (tout ce qui manque au stock, dont ce qui sera retiré), <modèle>_pistes.csv (les groupes de piste)

   Pour comparer les scores : EmbeddingStore(r"C:\Users\ll34272\embeddings_pc\_mis_de_cote", "birdnet-bacpipe1.3.5_pistes_<aaaammjj>").load()
   La partition d'origine n'est remplacée qu'une fois sa copie écrite ; relancer la commande après une coupure ne double rien.
   La table windows n'est pas touchée. Place libre sur C: le 20/11 : 14 Go (les copies de birdnet et birdnet_v3 y vont).

5. lancer l'encodage (perch_v2, birdnet, birdnet_v3 sur tout ce qui leur manque, puis audioprotopnet sur tout le corpus, sur F:) :
