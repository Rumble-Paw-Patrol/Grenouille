Remplacer <depot> par le dossier du dépôt et <encodeur> par le nom de l'encodeur (ex. birdnet_v3).

pour lancer l'encodage dans powershell :

Start-Process powershell -WindowStyle Hidden -ArgumentList '-NoProfile','-ExecutionPolicy','Bypass','-File','<depot>\scripts\encodage\encode_modele.ps1','-Encoder','<encodeur>'

voir où ça en est :

Get-Content <depot>\rapports\embed_<encodeur>.log -Tail 3

arrêter l'encodage :

Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*encode_modele.ps1*' -or $_.Name -eq 'blanci.exe' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
